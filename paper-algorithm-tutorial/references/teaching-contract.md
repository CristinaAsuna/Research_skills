# 从论文机制到可完成的练习

## 学习者与默认交付

默认学习者了解 Python、基础 Tensor 和自动求导，尚不能从一个空函数设计整个模型。目标是独立实现论文机制并接入 CPU 训练闭环。基础不熟时给前置练习，不先要求重复自评。

沿用项目已有组织方式；新课程推荐如下接口：

|产物|要求|
|---|---|
|README.md|准确论文身份与来源、前置、学习顺序、数据流/形状、命令及 toy 差异|
|reference_<paper>.py|完整可运行答案；不依赖未填写的学生代码|
|lesson*.py|模块属性和外围代码已提供，论文关键计算拆成小函数/方法 TODO|
|HINTS.md|思路、张量操作、伪代码三级可选提示|
|practice_<paper>.py|真正组合 lesson；`build_toy_<paper>()` 的返回类型和维度配置明确|
|check_lessons.py|`--lesson N` 选择一关；省略则检查各关；默认 practice|
|run_<paper>_demo.py|`--implementation reference\|practice`，默认 reference；两模式相同机制验收|
|接线测试|使用测试替身验证学生函数被调用，替身不能写回 lesson|
|recipe/|真实数据、预训练权重、计算条件与评估路线；配置骨架可校验，尚未实现能力明确标出|

PyTorch/CPU/合成数据是默认值。用户指定其他框架或规模时调整，保留相同教学目标；不要将已指定的真实复现任务缩成 toy。

## 每个微任务

一个微任务应有明确的输入、输出和数学作用，签名提供必要的模块、mask、labels 和配置。前置知识在关卡开头声明。

1. 解释为什么需要这一步、它位于完整模型何处。
2. 写出公式、轴变化与输入/中间/输出形状。说明 B/N/D 等符号。
3. 给一个可以手算的小输入和预期结果。
4. 初始化参数与模块，编号 TODO 仅留下关键计算；每个大机制拆成若干可独立检查的子任务。
5. 提供常见错误及局部检查命令；尚未完成时报告具体函数和子任务。
6. 在单独提示文件中提供三个层次，学习者可以逐层阅读。

不要把全部实现藏在提示末尾的一句“对照参考答案”。工程 scaffolding 可以给出；论文核心机制仍需学生实现。

### 例子：图像占位符展开

手算输入：文本 `[3, image, 7]`、两个视觉 tokens、标签 `[-100,-100,7]`。输出标签应为 `[-100,-100,-100,7]`。

拆成：单样本文本 embedding/视觉替换、单样本 mask/labels 展开。外层 batch 遍历、输入校验、右 padding 可提供。这样学习者先验证两个小 helper，再验证整个 batch，而不是一次写完整 packing 函数。

### 例子：target mask 采样

先实现给定起点的矩形/cuboid，再实现 union/complement。随机候选枚举和有限搜索提供骨架。清楚区分“True 表示被选为 target”和“True 表示 attention 允许看见”；论文不要求精确补集或不重叠时不能强加该 toy 合同。

## 参考与练习接线

共享基础只练一次，论文默认复用。论文专有 routing、objective、teacher 或训练阶段由论文练习承担。

外围 backbone、tokenizer stub 或训练工具可提供；当前练习的核心计算不得调用参考答案。参考模型应提供少量明确替换点，使 practice 的 forward 直接调用学生机制，避免先运行答案再覆盖结果。

未填写的练习使用 NotImplementedError，检查器明确定位并返回非零。真实数值/语义错误必须失败，不可作为“未完成”吞掉。默认参考 demo 不依赖练习完成。损失和训练步骤也应经过练习路径，不能只接一个无关辅助函数来宣称闭环。

## 有意义的验收

按算法选择相关检查：

- 切片/索引：编号张量、局部内容、token 次序、逆变换；不能只有 shape。
- Attention：手算值、遮蔽信息隔离、全遮蔽行行为；区分 mask 约定。
- 蒸馏：有效 view 配对、teacher detach、masked-only 梯度、center 与 EMA。
- JEPA：student 看哪些 tokens、teacher 编码与 gather 顺序、目标位置和 stop-grad。
- 多模态：占位符展开、answer-only labels、padding、next-token shift、训练阶段梯度边界。
- 动作策略：越界 chunk/有效位、固定噪声重参数化、训练/推理 latent 分支及时间融合手算。
- 整模型：有限 loss、反向传播、应该更新的参数变化、冻结参数保持不变；适用时验证确定性 eval/generation。

用测试替身验证 lesson 路由和必要的训练步骤，可模拟填答后的整模型；这不等于学生完成课程。产品实现不能 runtime monkeypatch 或异常回退答案。不要以随机 toy loss 必须持续下降作为一般验收。

## 论文与复现边界

把输入 → 中间表征 → 监督目标 → 参数更新对应到原论文/官方代码。在 README 分别标出保留的机制和 toy 简化：网格/分辨率、采样分布、tokenizer、位置编码、损失归约、训练日程等。

提供从 toy 到真实实验的下一步：数据格式、权重来源、训练资源、优化策略、评估协议。配置验证成功只能说明合同通过；真实训练和论文指标需分别记录证据。
