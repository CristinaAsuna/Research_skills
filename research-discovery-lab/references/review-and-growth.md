# 复盘与成长

复盘的目的是把一次实验变成用户能力的增长：校准预测、提炼招式、练习 taste，同时为 harness 收集改进证据。先核对结论，再和用户反思。

## 1. 核对结论

- **数字**：SUMMARY 中的每个数字都能在 `results/E*.json` 中找到；均值和 min–max 与 seeds 一致。
- **图**：逐张打开 `figures/`，确认"怎么读这张图"描述的形状真实存在；检查坐标轴、色标、图例；代表性 seed 的选择符合规则。
- **对照 PLAN**：执行记录交代了全部偏差，并且没有挑 seed、改指标、事后调阈值。
- **结论强度**：toy 结论没有写成论文结论，相关没有写成因果，"这个 toy 不能说明什么"写得具体。
- 发现问题就直接修改 SUMMARY，并在执行记录中注明"Reviewer 修正：……"。

## 2. 反思对话

和用户一起逐项进行，记录原话；不要一次抛出全部问题。

1. **预测对照**：逐个实验给出结果，先请用户自己判断是否命中，再问"你当时依据什么？现在看漏了什么线索？"
2. **发现过程**：把用户在 DISCOVERY §1 的猜测和重建并排，问"如果早注意到哪条线索，你就能猜到？"
3. **招式**：问"这次哪一步最有用？下次看到什么信号你会想到它？"把回答提炼成招式：要么是新招式，要么给已有招式补一个例子。
4. **taste**：请用户先写这篇论文选题的优点和不足、"如果我是作者下一步做什么"，以及四维评分（重要性、意外性、可检验性、简洁性，每项 1–5）。agent 再给出自己的评分和理由。分歧 ≥2 分的维度讨论一下，但不修改用户的分数。
5. **下次练习重点**：只选 1 条，而且要具体，例如"下次先列 2 个竞争解释，再看论文的消融"。

不要代写用户的话。用户不想写就记"用户跳过"。

## 3. 校准评分

- **方向命中**：预测的变化方向（升、降、不变、非单调）与结果一致。
- **幅度命中**：数量级或预测区间正确；预测没有给出幅度时记"不适用"。
- **无法判定**：预测模糊到无法判定时记为未命中，并把"预测要可判定"列为下次练习重点。
- LEARNING.md 的预测校准表每个 topic 记一行，并更新累计方向命中率。

## 4. 阶段与脚手架

| 阶段 | 用户做什么 | agent 做什么 |
| --- | --- | --- |
| S1 跟随 | 预测 toy 结果 | 重建发现过程，设计全部 toy |
| S2 推测 | 揭晓前猜关键观察与假设 | 揭晓并分析差距，设计 toy |
| S3 设计 | 先自己设计 toy（旋钮、基线、图规格） | 批评、补全，写成 PLAN |
| S4 质疑 | 提出竞争解释或论文没做的追问 | 设计检验它的 E3 及之后的实验 |
| S5 原创 | 从 INSIGHTS 的开放问题提出自己的问题 | 帮助收敛成可检验的假设和 toy |

- **升级**：连续 2 个 topic 方向命中率 ≥70%，并且从 S3 起，用户的设计最多只需要 1 处重大修正。重大修正指会改变结论的缺陷，例如缺对照、旋钮混杂、指标被平凡解满足。
- **退回**：连续 2 个 topic 方向命中率 <40%，退回上一阶段。
- Reviewer 在复盘时提议升级或退回，用户确认后修改 LEARNING.md 的"当前阶段"。

## 5. 合并更新根目录文件

- **EXPERIMENTS.md**：状态改为 `reviewed`；一句话发现不超过 40 字；核对发现原型。
- **INSIGHTS.md**：
  - 只写有证据的认识。
  - 先找能合并的已有条目；改写、降级或删除都优于追加。
  - 每条标注置信度：toy / 小真实 / 论文声称。
  - 新的开放问题写进"开放问题与候选 topic"。
- **RESEARCH_MOVES.md**：新招式编号顺延；同义招式合并；超过上限时合并最相近的两条。给已有招式补例子时写上 topic 链接。
- **LEARNING.md**：更新校准表、学习记录、下次练习重点和当前阶段。
- **HARNESS_LOG.md**：在摩擦指标表加一行；满足门槛时写提案，见 [harness-rsi](harness-rsi.md)。

## 6. 复盘常见错误

- 只看结论，不看图。
- 替用户总结"你学到了什么"。
- 把未命中的预测说成"部分命中"来安慰用户。校准只有诚实才有用。
- 每次复盘都往 INSIGHTS 追加条目，导致文件膨胀。
